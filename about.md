# Plan of this project

# Structure of the app
- supabase with nextjs
- user management as a center
- other applications should be modular and independent
- modular and independent components
- ui and component framework separate
- pwa
- mobile app - responsive design

## Features
- User authentication and authorization based on https://github.com/supabase/supabase/tree/master/examples/user-management/nextjs-user-management
- todos
- notes
- newspaper
  - I want to be able to create myself a newspaper that I can print out or send to kindle. It should be configurable and customizable.
  - Stuff like weather, rss feeds, notes, static text and more. Ofc should be connected to the user management system and the other apps.
- rss feed reader
  - I want to be able to read rss feeds from different sources and display them in a user-friendly way.
- article reader
  - share articles using android and scrape the content.
  - same for youtube videos
